# Планировщик задач (Go Final Project)

Веб-сервис для управления списком задач с поддержкой повторений, дат и авторизации.

## Функциональность
- Добавление, редактирование и удаление задач
- Отображение списка ближайших задач
- Поддержка повторяющихся задач (daily, weekly, monthly, yearly)
- Авторизация по паролю (JWT)
- Хранение в SQLite
- Docker-контейнеризация

## Выполненные задания со звёздочкой

1. Конфигурация порта через переменную окружения TODO_PORT
2. Конфигурация пути к БД через переменную окружения TODO_DBFILE
3. Полноценная реализация NextDate (еженедельные и ежемесячные правила)
4. Поиск по задачам (заголовок, комментарий, дата)
5. JWT аутентификация
6. Docker-контейнеризация

## Локальный запуск

### Переменные окружения
TODO_PORT     - порт сервера (по умолчанию 7540)
TODO_DBFILE   - путь к файлу БД (по умолчанию ../scheduler.db)
TODO_PASSWORD - пароль для авторизации (опционально)
### Команды
# установка зависимостей
go mod download

# запуск сервера
go run ./cmd/server

# запуск с параметрами
TODO_PORT=8080 TODO_DBFILE=/custom/path/db.db TODO_PASSWORD=123 go run ./cmd/server
После запуска открыть в браузере: http://localhost:7540 (или ваш порт)
